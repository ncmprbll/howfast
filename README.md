# Howfast
Howfast is a testament to your keyboard typing speed.

# Usage
```
Usage: howfast [OPTIONS]

Options:
  -f, --dictionary-path <DICTIONARY_PATH>
          Path to the dictionary (see dictionaries for examples) [default: dictionaries/english_1k.txt]
  -t, --typing-time <TYPING_TIME>
          The amount of seconds you get for typing [default: 30]
  -l, --render-lines <RENDER_LINES>
          Amount of lines to render at a time [default: 3]
  -p, --padding <PADDING>
          Universal padding from all sides [default: 1]
  -w, --width-percent <WIDTH_PERCENT>
          How wide should the typing area be in percent (1 to 100) [default: 50]
  -g, --with-punctuation
          Enable punctuation
  -d, --debug <DEBUG_FLAGS>
          Enable debugging options with comma separated
          values - source_text and text_oveflow are available
  -h, --help
          Print help
  -V, --version
          Print version
```
